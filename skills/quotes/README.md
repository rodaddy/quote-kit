# skills/quotes/

The `quotes` skill itself, plus every file it reads. `SKILL.md` carries the
behavior: a plain request or a filled quote form becomes a numbered, logged,
branded quote.

- `SKILL.md` - behavior and hard rules.
- `USER-CONFIG.md` - output folder for finished quotes; the installer edits it.
- `rate-card.md`, `services.md` - the user's prices and per-service plain-words
  descriptions, exclusions, and assumptions, filled by the pricing interview.
- `workflows/`, `scripts/`, `templates/`, `ledger/` - see each folder's README.
  `branding/` is created here at install from the branding interview.
